MARKER IMAGES FOLDER
====================

Place your PNG marker images here with the following names:

- marker_free.png      (for FREE state - green markers)
- marker_partial.png   (for PARTIAL state - yellow markers)
- marker_full.png      (for FULL state - red markers)
- marker_unknown.png   (for UNKNOWN state - gray markers)

Recommended size: 24x24 pixels or 32x32 pixels
Format: PNG with transparency (alpha channel)

If images are not found, the application will use default colored circles.
